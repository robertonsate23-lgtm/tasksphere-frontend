# TaskSphere Frontend

## Overview

TaskSphere Frontend is a React application that connects to the Flask REST API to provide an employee management dashboard.

## Features

- Secure Login
- Dashboard
- Employee Management
- Projects
- Tasks
- Attendance
- Leave Requests
- Notifications
- Reports
- Settings
- Protected Routes
- JWT Authentication

## Technologies

- React
- React Router
- Axios
- CSS
- Vite

## Installation

```bash
git clone <repository-url>
cd tasksphere-frontend
npm install
